# Aegisub Diorite

一个基于 [Aegisub Toshi-ban](https://github.com/amanosatosi/Aegisub_Toshi-ban) 的、方便直接在字幕中插入本地化文本的 Aegisub 改版。

> ### 所有代码更改均借助 AI 完成。
> 
> 使用该版本即代表您已充分理解并能够接受相关风险。

当前阶段建议使用 Portable（便携版），以免不同版本的 Aegisub 配置文件出现冲突。

## 新功能/改动

### 字幕本地化匹配

导入本地化文件后，可快速根据当前字幕行的文本搜索并插入对应的本地化文本。

当前版本只为底特律变人的本地化文件提供了支持，未来可能会开发支持多种游戏的可拓展模块。

### 单条硬字幕扫描

~~利用 Aegisub Toshi-ban 使用的 PaddleOCR 引擎~~ 利用新版 PP-OCRv6 引擎，扫描指定区域内的硬字幕，提取起止时间与文本。

已知问题：
- 字幕与背景对比度较低时时间轴识别结果易出错。
- 未对淡入淡出字幕进行针对性测试，效果可能不佳。

### 全片硬字幕扫描

扫描整段视频在指定区域内出现的硬字幕，逐条提取起止时间与文本。

扫描前可选择以 100%（原始）、75%、50%、33%、25% 的分辨率处理指定区域；档位越低处理越快，但越小或对比度越低的字幕越容易漏检。

已知问题：
- 输出的部分字幕行的文本会重复
- 会识别少量非字幕文本


### 对 Aegisub Toshi-ban 的其他改动

- 默认启用 OCR 模块支持
- 默认启用深色模式支持（可选设置）
- 可选 AV1 硬解
- 补上了部分汉化
- 暂时只专注于 Windows 平台的支持

## Q&A

#### Q：改版诞生的原因？
A：为了给 About Oliver 的底特律实况做字幕。底特律有着大量的游戏内硬字幕，AI 转录这些字幕不够准确，也容易漏句。

#### Q：为什么这个改版要叫 Diorite？
A：因为 PaddleOCR 的幻觉和 Oliver 的量子记忆力有得一拼。

#### Q：前面列出的 Bug 会修吗？
A：目前优先考虑功能开发，Bug 将在之后处理。
